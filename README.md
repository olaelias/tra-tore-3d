# TRÄ-TORE 3D
 
A Duke Nukem 3D-inspired parody game built entirely in a single HTML file.
 
TRÄ-TORE 3D started as a simple experiment:
 
> How far can AI-assisted vibe coding actually go?
 
Instead of creating yet another calculator or todo app, the experiment evolved into a complete retro FPS parody featuring its own renderer, enemies, combat system, audio, HUD, minimap and game loop.
 
The result is a small but fully playable browser game about a Swedish woodworking teacher armed with a RUBANK, fighting his way through a school overrun by rebellious wooden creatures.
 
---
 
## Features
 
- Retro raycasting renderer
- First-person combat
- Enemy AI
- Minimap
- HUD and health system
- Procedural sound effects
- Simple background music
- No dependencies
- Single-file implementation
 
---
 
## Controls
 
| Key | Action |
|-------|----------|
| W A S D | Move |
| Mouse | Look around |
| Left Click | Attack |
| Space | Attack |
| M | Toggle music |
| ESC | Release mouse |
 
---
 
## Run
 
Download the HTML file and open it in a modern web browser.
 
No installation required.
 
---
 
## Purpose
 
This project was created primarily to explore:
 
- AI-assisted development workflows
- Rapid prototyping through vibe coding
- How far a single-file browser game can be pushed
- The practical limits of AI-generated code
 
While the project is intentionally comedic, the underlying systems (rendering, game loop, collision handling, sprite projection, audio, and state management) were implemented as part of a genuine programming experiment.
 
---
 
## Technical Notes
 
Built with:
 
- HTML5 Canvas
- Vanilla JavaScript
- Web Audio API
 
No frameworks, no external libraries, and no build process.
